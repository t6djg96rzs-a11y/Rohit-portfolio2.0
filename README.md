# Rohit Khatwani — Videographer & Editor Portfolio

A dark, cinematic portfolio website for Rohit Khatwani, a videographer, cinematographer and video editor based in Indore, India. It opens with an anime-inspired dimension-slash intro and is built as a single `index.html` file with no frameworks or build step.

## Highlights

- **Dimension-slash intro (about 3 seconds):** the name rises, a pillar of light strikes with a black cut line and branching lightning, the screen splits in half, shatters into shards, and reveals the main page.
- **Equinox hero:** a giant "ROHIT" over a half-light, half-dark disc with rotating tick rings, a cursor-following shadow spotlight and parallax.
- **Atmosphere:** floating dust particles, film grain, a cursor glow, a scroll progress line and large outlined watermarks behind each section.
- **Responsive and accessible:** works on phones and desktops, and respects reduced-motion settings.

## Sections

About, What I do (7 services), Tools I use, Selected reels (5 Instagram reels), Worked with (client Instagram pages), How I work, Education and Contact.

## Tech

Plain HTML, CSS and JavaScript in one file. The only external resource is the Archivo typeface from Google Fonts.

## Run it

Open `index.html` in any browser. To host it, turn on GitHub Pages for this repository (Settings > Pages > Deploy from a branch > `main` / root).
